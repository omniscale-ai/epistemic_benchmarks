# Орбитальный эпизод: «скрытое внутреннее тело против изменённого закона силы» (итерация 2)

Дата: 2026-11-16. Код: `src/abductbench/episode/orbitworld.py` (мир), `orbitfamily.py` (наблюдения, меню,
эталонные семейства), `orbitmetrics.py`, `orbitbaselines.py`, `orbitworkspace.py`; протокол, песочница,
сервер и запуск агента общие с миром распада (`families.py` — адаптер семейства). Тесты: `tests/test_episode_orbit.py`.
Предварительная проверка и отвергнутые варианты: `docs/episode-orbit-feasibility.md`.

## Что выяснилось при построении (физика, а не настройка)

1. **Внешняя цель (Уран/«Нептун») не даёт честной пары**: закон k/r^n, подогнанный к внешней планете,
   ломает внутренние; тело на ~24 а.е. закон не имитирует. Отвергнуто.
2. **Монополь.** Внутреннее тело в среднем действует на внешние орбиты как добавочная центральная масса;
   поправка с n = 2 — это просто «неверная масса звезды». Поэтому публичный `gm_central` по правилам мира
   определён по движению планет и включает массу тела; у конкурента n ≥ 3.
3. **Соглашение о начальных данных.** Гелиоцентрические элементы в момент, когда звезда быстро движется
   вокруг общего с телом центра масс, дают всем планетам фазозависимый «толчок» (артефакт соглашения).
   Принято чистое соглашение: планеты движутся вокруг центра масс C всего, что внутри орбиты самой
   внутренней планеты; элементы — оскулирующие относительно C; T0 ставит в C одну массу.
4. При таком соглашении **вековое действие внутреннего тела совпадает с центральной силой ~1/r⁴**
   (квадруполь): сопряжённая сила получается с n ≈ 4–5. Различают механизмы только несимметричные и
   переменные эффекты: короткопериодические (синодические) члены, влияние на соседнюю планету при
   оскулирующих элементах эпохи, и само тело (поиск).
5. **Фаза тела** влияет на средний период цели через оскулирующие элементы эпохи (≈25% векового дрейфа
   к 10 циклам), а короткопериодический узор требует знания радиуса тела с точностью ~10⁻⁴ —
   по данным эпизода он непредсказуем по фазе.

## Мир и эпизод

- Звезда + 4 известные планеты (вымышленные имена), цель — самая внутренняя (Ithe) в обоих мирах.
- «Тело»: круговая орбита a/a_цели ~ U(0.2, 0.3), случайная фаза; масса задаёт |R(10)| ~ U(20, 60)″.
- «Сила»: −k r^(−n) на все планеты; (n, k) подогнаны к невязкам цели мира тела на окне A (сопряжённая пара).
- A: невязки цели, 40 точек за 10 циклов, σ = 1″.
- Меню (бюджет 2): невязки другой планеты (40 точек, 0–10); продление цели (20 точек, 10–15);
  плотная серия цели (200 точек за 0.5 цикла, начало 0–12); поиск в окне ≤ 10° (вероятность обнаружения 0.8,
  ложные — Пуассон 0.3).
- Скрытая проверка: плотная серия цели в эпоху 15–15.5 и невязки трёх других планет на 12–15 циклах;
  оценка — средняя по точкам одномерная энергетическая дистанция в единицах σ, по блокам.
- Модель агента возвращает n реализаций (с шумом) невязок или число обнаружений.

## Эталон (знает оба семейства, видит только данные эпизода)

- Сила: сетка n ∈ [3, 5.5] шаг 0.25, k линейно.
- Тело: сетка (a/a_цели ∈ [0.18, 0.32] шаг 0.02) × 24 фазы, масса линейно; отклик разделён на медленную
  часть (скользящее среднее за синодический период; подгоняется с фазой, с уточнением сплайном по a и
  фурье-интерполяцией по фазе) и быструю (синодическую) часть, которая входит как дисперсия, усреднённая
  по фазам. Прогноз эталона для тела — ансамбль со случайной быстрой фазой.
- Эталон **не прицеливает поиск** (быструю фазу он не оценивает); ценность поиска может появиться только
  из вывода самого агента.

## Проверено численно (24 мира, данные A с шумом)

- Неоднозначность A (|Δℓ| < 3 нат): 22/24 миров тела, 23/24 миров силы.
- Медианная ожидаемая информация измерения (нат): соседняя планета 21–28, плотная серия в эпоху 12 — 13–24,
  в эпоху 6 — 4–6, в эпоху 0 — ≈1, продление 1.5–3, дальние планеты 0.3–3. Лучшее измерение по мирам —
  от ≈4 до сотен нат: часть миров трудна при бюджете 2.

## Ограничения

- Правила мира определяют C как «центр масс всего внутри орбиты самой внутренней планеты» — это нужно для
  согласованности соглашения, но может подталкивать к гипотезе тела (текст одинаков в обоих мирах).
- Эталон приближён (фазовая маргинализация быстрой части, сетки); его вердикты пересмотра и флаг
  сверхуверенности (|Δℓ| < 3 против весов Акаике) расходятся у самого эталона в части эпизодов
  (3/10 `unjustified_switch` и 3/10 «сверхуверенность» у адаптивного эталона).
- Параметры тела (радиус, фаза, масса) по данным эпизода вырождены; оцениваются предсказания, не параметры.
- Модели агента интегрируют N тел; эпизоды значительно дороже по времени, чем в мире распада.
