# Известные ограничения и решения до первого реального прогона

Статус на 2026-11-12: реализованы все 13 задач плана, тесты проходят (312 passed, 1 skipped — рендер Quarto, так как quarto не установлен). Ниже то, что НЕ исправлено и требует решения или проверки человеком.

## Нужно решить / сделать перед реальными прогонами
1. **Изоляция агента (I1).** Агент запускается как тот же пользователь ОС, Bash разрешён. Через Bash можно прочитать `rubrics/`, исходники генераторов, каталог состояния (бюджет в режиме 2). Для честных прогонов нужен контейнер/bwrap или отдельный пользователь ОС; в режиме 2 симулятор лучше отдавать через прокси вне репозитория. Остаток C1: каталог результатов `runs_root/<variant_id>/` создаётся до запуска агента и виден через `ls ../../..` (cwd агента теперь нейтральный, но выше по дереву имя варианта достижимо). Простой фикс: создавать каталог результатов после завершения агента или держать его вне `runs_root`.
2. **Асимметрия цели в орбитальной паре (I4).** Для entity целевая планета внешняя, для no_entity внутренняя (как Уран/Меркурий). Агент может отвечать «внешняя → скрытая планета, внутренняя → изменённый закон» без анализа данных. Варианты: одна и та же цель в обоих случаях (нужна перенастройка силы сигнала), либо считать и публиковать базовый «безэвиденсный» ответ в таблицах.
3. **«Экстраполяция» в бете (I6).** Для no_entity около 95% точек экстраполяции лежат внутри публичного окна энергий, для entity около 50%. Метрику стоит переименовать («вне ядра домена») или реально отложить окно.
4. **Метрика закона для орбиты entity** решается обычной подгонкой кубическим полиномом в стадиях a и d (по оценке финального ревью) — базового полиномиального столбца нет. Основную нагрузку несут `ENTITY`, границы и рубрики.
5. **Beta no_entity, стадии a/c/d** физически одинаковы (m_X влияет только на entity), поэтому разрыв a→c, a→d там ≈ 0 по построению.
6. **Живой прогон CLI не выполнялся.** Флаги `claude -p` (агент: `--restricted --tools ... --permission-prompts none ...`; судья/аудит: `--tools "" --setting-sources ""`) проверены только по `claude --help`. Перед массовым запуском один пробный прогон с маленьким `--max-budget-usd` (сейчас по умолчанию 5.0).
7. **Quarto** не установлен: `report/report.qmd` проверен только исполнением его python-ячеек на фикстуре.
8. **Судья** и **аудит** используют ту же модель (`sonnet`), что и агент по умолчанию; отличается только промпт. Можно задать другую модель константами `JUDGE_MODEL`/`AUDIT_MODEL`.
