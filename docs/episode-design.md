# Абдуктивный эпизод: мир распада (итерация 1)

Дата: 2026-11-13. Статус: реализовано и проверено локально; реальный прогон LLM не выполнялся.
Код: `src/abductbench/episode/`. Старый трек (`tasks/`, `evaluate/`, `runner.py`, `sim_cli.py`) сохранён как **legacy**, см. раздел 9.

## 1. Что считаем свидетельством абдукции

Различаем три уровня и не выдаём один за другой:

1. **Выбор объяснения из меню** (условие `menu=True`: в task.md перечислены виды `carrier`/`loss`/`other`).
2. **Самостоятельное выдвижение объяснения** (условие `menu=False`: видов нет; агент сам должен
   предложить «невидимый носитель уносит энергию»). Правила мира прямо описывают только закон
   потерь в материале, поэтому гипотеза носителя в этом условии не подсказана.
3. **Новое различающее предсказание из объяснения**: исполняемая модель агента, зафиксированная до
   скрытой проверки, предсказывает совместное распределение (энергия частицы, импульс отдачи
   дочернего ядра) на тонком источнике — наблюдаемую величину и условие, которых агент ни разу не видел.

Свидетельство абдукции в эпизоде — не метка механизма, а цепочка, где каждое звено проверяется числом:
(а) модели гипотез объясняют начальные данные одинаково хорошо → (б) агент выбирает измерение, на
котором его же модели расходятся → (в) предсказания, записанные оркестратором до измерения,
сравниваются с результатом → (г) пересмотр согласуется с перевесом свидетельства → (д) итоговая
модель верно предсказывает скрытую величину, которую нельзя получить продолжением подогнанной кривой.

## 2. Выбранный сценарий и почему бета, а не орбиты

Выбрано бета-семейство, переписанное как условный «мир распада» (вымышленные названия, единица `unit E`).

- **Согласованный генератор дёшев**: полное событие распада (точная трёхчастичная кинематика по
  Далицу, 1e-16 по энергии, 0% нарушений импульсного треугольника) → перенос в материале → приборы.
  Орбиты требуют N-тельного интегрирования на каждый запрос и подгонку.
- **Содержательная неоднозначность строится и проверяется численно**: мир «потери в источнике»
  (T0 верна, прибор/материал искажает) калибруется так, что его спектр при номинальной толщине
  близок по KL к миру «скрытый носитель» (KL ≈ 0.001 нат/событие → при 400 событиях ≈0.4 нат).
  Для орбит получить честную неоднозначность «тело против закона» на одной цели сложнее (вековая
  прецессия против периодики различимы уже по длинному ряду).
- **Независимая проверка механизма** естественна: отдача дочернего ядра определяется в момент
  распада. При потерях она постоянна (`p_R = p(Q)`), при носителе широка и зависит от массы носителя.
- Локальная проверка всех seed и baseline занимает минуты.

## 3. Мир (явные правила, сообщаемые агенту)

Внутренняя единица — Q. Публичные энергии = внутренние × `Q_pub` (из `world_seed`) × `unit_scale`.

- Сохранение энергии-импульса; состояния распада заполняют Лоренц-инвариантное фазовое пространство
  с постоянным матричным элементом. Это **не** учебная форма Ферми `pE(Q−T)²`: для трёх тел спектр
  ∝ p₁* p₂*. Запомненная формула даёт видимую ошибку.
- Перенос: частица, пересекая источник толщины t, теряет `L = a·t + Gamma(b·t, c)`; константы
  материала не измерены. Закон одинаков во всех мирах; в мире носителя потери малы (a=0, b=2, c=0.002).
- Приборы: спектрометр (σ=0.02Q, окно 0.1–1.3Q, остановившиеся частицы не регистрируются);
  калориметр вокруг источника (поглощает лёгкую частицу и дочернее ядро, σ=0.03Q); детектор отдачи
  (2%), **доступен только скрытой проверке**.
- Скрыто: механизм, масса носителя `m_x ∈ U(0, 0.3)Q`, константы материала мира потерь.

Что раскрывает эта рамка: класс законов переноса, правило фазового пространства, перечень приборов.
Тем самым проверяется абдукция внутри заданной физики, а не открытие законов переноса или кинематики.

## 4. Эпизод

A. Начальные данные: спектр при t=1, 400 событий. Обе причины совместимы в 88–93% миров (проверено на 40 seed; остальные помечаются `lean_*`).
B. `./episode register prereg.json`: текущая гипотеза, ≥1 альтернатива (у каждой исполняемая модель
   `simulate(query, n, seed)`), доверия, «что не определено», выбранное измерение, ожидаемый результат
   словами. Оркестратор копирует модели вне рабочей области и **сам** исполняет их для выбранного
   измерения в песочнице; эти выборки и есть оцениваемый прогноз. Позже заменить его нельзя.
C. `./episode measure`: выполняется ровно зарегистрированное измерение. Правильность не сообщается.
   Меню: спектр при t∈[0.25,3] (n≤400) или калориметр (n≤400). Бюджет 2 цикла B–C.
D. `./episode final final.json`: итоговые гипотезы и доверия + предсказательная модель. Скрытая
   проверка (`recoil_coincidence`, t=0.05) считается оценщиком после эпизода; через интерфейс
   измерений она недоступна.

## 5. Показатели (без единой суммы)

Все безразмерны: энергии делятся на Q, импульсы на p_Q (импульс лёгкой частицы при T=Q; обе величины
публичны). Проверяется тестом инвариантности к `unit_scale`.

| показатель | как |
|---|---|
| `initial_fit` | энергетическое расстояние (ED) между выборкой модели и большой выборкой истины для начального условия; для сравнения — ED эталонных подгонок обоих семейств |
| `design_info_own` / `design_info_ref` | ожидаемый log-BF выбранного измерения между **своими** H1 и H2 агента; и между эталонными подгонками обоих семейств к данным агента; доля от максимума по меню |
| `forecast` | ED прогноза каждой гипотезы до измерения к результату; реализованный log-BF(alt:cur) по гистограммам их прогнозов |
| `revision` | `justified_switch` / `justified_keep` / `unjustified_*` / `weak_evidence` по знаку и силе реализованного log-BF (порог 3 нат) |
| `check` | ED совместного распределения (T/Q, p_R/p_Q) скрытой проверки; якоря: истина-с-подсказкой (шумовой пол) и противоположный механизм |
| `consistency` | заявленный вид vs поведенческий класс модели по зондам (калориметр/Q, чувствительность к толщине, кинематические границы отдачи при заявленной массе) |
| `uncertainty` | доверие агента к классу «носитель» против эталонного апостериори по тем же данным; флаг сверхуверенности, если агент ≥0.9 при эталоне в (0.1, 0.9) |

Пересмотр не поощряется сам по себе: сохранение подтверждённой гипотезы — `justified_keep`.
Неуверенность при неидентифицируемости не штрафуется: эталон уверенности — апостериори по доступным данным,
а не истина генератора; скрытая проверка оценивается собственным правилом (энергетический скор),
при котором смесь не проигрывает уверенной догадке в среднем.

Категория экземпляра (`ambiguous` / `lean_carrier` / `lean_loss` / `no_data`) определяется по фактическим данным:
максимальное отношение правдоподобий эталонных семейств «носитель(m)» и «два тела + потери(a,b,c)», |Δℓ| < 3 нат —
неоднозначно. Для сравнения с доверием агента сообщается и апостериори с весами Акаике (равные априорные); оно
зависит от штрафа за параметры, поэтому флаг сверхуверенности опирается на Δℓ. Числа: `docs/episode-baselines.md`.

## 6. Контроли и что они исключают

| контроль | исключаемое объяснение успеха |
|---|---|
| нет данных (`condition=no_data`) | знание ответа без наблюдений; хеджирование не штрафуется |
| парный мир (тот же seed, противоположная причина) | метаданные/имена кодируют ответ (метаданные пары тождественны) |
| меню / без меню | различие уровней 1 и 2 (только для LLM; локально не сравнимо) |
| эвристика по одному признаку спектра | «класс угадывается по простому признаку» |
| феноменологический предсказатель (повтор спектра, наивная отдача T0) | «достаточно подогнать наблюдаемое» |
| неадаптивный и случайный план | «любое измерение одинаково полезно» |
| учебный ответ (безмассовый носитель, спектр Ферми) | «достаточно запомненного ответа» |
| условный эталонный решатель (знает оба семейства) | демонстрация разрешимости при той же информации |
| `no_measurement` (бюджет 0) | данных для выбора механизма недостаточно |
| `t0_sufficient` (дан второй спектр при t=2.5) | простой случай, где уже T0-данных хватает |

Подставной агент с истиной называется `truth_fed` и служит только проверкой протокола и шумового пола.

## 7. Недоступные выводы

- Отсутствие запоминания не доказывается; мир уменьшает пользу памяти (иная форма спектра, массивный
  носитель, вымышленный словарь), но учебная идея «нейтрино» остаётся узнаваемой.
- Открытый текст гипотез не связывается с моделью автоматически; связь проверяется только для
  заявленных видов и поведенческих зондов. Текст сохраняется для чтения человеком; судья не используется.
- Смешанные гипотезы (носитель + значимые потери), несколько носителей и «статистическое несохранение»
  в эталонные семейства не входят; модели агента могут их реализовать и оцениваются только предсказательно.
- Подбор пары миров по KL — сознательная конструкция; на другом распределении миров неоднозначность может отсутствовать.

## 8. Изоляция

Сервер эпизода (вне песочницы) хранит конфиг, журнал, снимки моделей. Агент в реальном прогоне
запускается в `bwrap`: видит только `/work` (рабочая область), свой Python (numpy/scipy), исполняемый
файл claude, отдельный пустой каталог конфигурации со скопированным файлом учётных данных; связь с
сервером — unix-сокет. Модели агента исполняются в отдельной `bwrap`-песочнице без сети с лимитами CPU/памяти.
Сухие локальные тесты могут работать без изоляции агента, это помечается `isolation: none` в манифесте.
Запуск настоящего claude внутри bwrap проверен только до `claude --version`.

## 9. Legacy

Старые 4 ступени × 2 семейства не изменены и не используются эпизодом. Их ограничения (рецензия
2026-11-13): ENTITY решается эвристиками 96/96; в beta/no_entity отдача из искажённой энергии;
в beta/d степень спектра не согласована с отдачей; DOMAIN произволен; режим входит в seed; допуск k
зависит от единиц; оракул режима 2 видит полную таблицу; нет изоляции ОС.
